# Security and disclosures

This is a host-side scheduling reference project, **not firmware** and not an operational exploit or device-updater tool.

- Do not submit proprietary firmware, personal identifiers, secret keys, device logs or vendor assets in issues or pull requests.
- Prefer reproducible synthetic inputs for bugs.
- Report any accidental disclosure of protected content privately to the repository maintainer; remove from Git history where necessary, rather than treating a deletion commit as sufficient.
- Any research on a specific device should respect ownership, relevant law and permissions. No firmware flashing or device mutation is part of this repository.
