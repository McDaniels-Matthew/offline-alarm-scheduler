# Provenance, IP and publication checklist

AI assistance was used in drafting and development. The maintainer is responsible for the code, tests, and provenance claims.

This repository contains an original scheduling reference implementation, synthetic test cases, original written explanations and public-standard Python-library use. It is not generated by extracting or translating any vendor's firmware code, and it is not an installable replacement for any product.

The author's personal device motivates feature requirements, but this repository does not claim any endorsement, affiliation or firmware integration. Names of manufacturers, if used, serve descriptive identification only.

## Before each public push

1. Inspect the full staged diff: `git diff --cached --name-status`, `git diff --cached`.
2. Run `python tools/audit_repo.py --root .`, then review false positives and gaps.
3. Run all tests.
4. Do not commit original firmware, mass decompiler exports, code copied from reverse engineering, private captures, keys, identifiers or proprietary visual assets.
5. Inspect Git history if committing from a previously used local repository: removing files from the latest tree does not erase them from earlier commits.
6. Clearly label unimplemented and target-dependent behavior.
